Fahad Tahir

10 years closing the books. Now I build the tools that close them faster.

v1.1 · 27 Sep 2026 Navy and champagne

This guide sets the look, voice and building blocks for Fahad's portfolio site and his LinkedIn cover. Fahad is a finance professional first. Automation is his edge. Every page should read like a finance CV that proves he also builds tools, and it should feel calm enough for a CFO and warm enough for a person.

01 · Brand personality

Calm, practical, curious, trustworthy, warm

These five words decide every design and copy call. Calm and trustworthy earn credibility with money. Curious explains the AI work without chasing hype. Warm stops the page from feeling like a corporate bio.

Calm

Plenty of space, one idea per section, no motion that competes for attention.

Practical

Every project states the manual problem, what he built and what changed.

Curious

Shows the tools by name (n8n, K2 Horizon, Power BI) and the hackathon he joined.

Trustworthy

Numbers are exact, rounded conservatively, and match the CV word for word.

Warm

First person, real photos of Fahad, and plain words a friend would use.

02 · Logo

There is no symbol. The name set in Geist is the logo, and the FT monogram stands in where space is tight, such as the favicon or the site header on mobile. The circle matches his round profile photo.

05 · Spacing and layout

A 4px grid with lots of air

Ramp's restraint comes mostly from spacing. Sections sit 96px apart on desktop and 64px on mobile. Content maxes out at 1120px, and text blocks at 65 characters.

Layout

12-column grid, 24px gutters, 1120px max width. Side padding is 24px on desktop and 16px on phones. Breakpoints: 640 / 900 / 1200.

Shadows

06 · Motion

Quick and quiet

Motion confirms that something responded. It never performs. Nothing on the page moves unless the reader did something, apart from one fade as each section scrolls into view.

fast · 120ms · ease-out
base · 200ms · ease-out
slow · 320ms · ease-in-out
reveal · 480ms · ease-out
TokenValueUse
dur-fast120msHover, press, link underline
dur-base200msCard lift, toggles, tabs
dur-slow320msModal open, dropdown
dur-reveal480msSection fade on scroll
ease-out(.2,.7,.2,1)Anything entering or responding
ease-in-out(.65,0,.35,1)Things moving across the screen
ease-in(.4,0,1,1)Exits, at 70% of the entry time

Section reveal: fade from 0.001 to 1 opacity and rise 12px, starting from a visible resting state so screenshots and link previews never show a blank page. With reduced motion turned on, everything appears instantly.

10 · Data visuals

Before and after, nothing more

The site shows results, not live data. The only chart is a before-and-after bar, and it follows the same colour rule as the metric component.

Monthly commission reporting prep, Canon. Source: Fahad's CV.

Colours

Before bar Navy 300. After bar Navy 900. Value label on a Champagne 300 tag. No other series colours exist.

Axes

Geist Mono 11px in Navy 500. Baseline Navy 200. Gridlines dotted Navy 200. Always start bars at zero.

Tooltips

Charts are static, so no tooltips. Label values directly on the bar and give the source underneath.

11 · Voice and content

Write it the way Fahad would say it

ItemRuleExample
PersonFirst person on the site. Third person only in the page title and meta description."I built…"
CurrencyISO code, space, figure. Lowercase m and k for millions and thousands.USD 2.5m · AED 45k
PercentagesNo space before %. Whole numbers unless the decimal matters.26%
Time savedShort units with an arrow. Round conservatively.30h → 3h
DatesThree-letter month and year. Use "to" in ranges, never a dash. "Present" in lowercase.Aug 2016 to Sep 2021
DecimalsOne decimal for millions, none for percentages and hours unless under 10.USD 2.5m · 2.5h
ButtonsVerb first, two or three words, sentence case, no full stop.Download CV · Copy email
ErrorsSay what's wrong and how to fix it. No "Oops", no apology."Enter a valid email address."
CredentialsExactly as on the CV, every time.ACCA, papers F1 to F9 completed
Tool namesOfficial spelling and case.n8n · K2 Horizon · Power BI · QuickBooks
PunctuationNo em dashes. Use a full stop or a comma instead. Serial comma on."Canon, Pearl Initiative, and LSN"

Words to avoid

Leverage, synergy, cutting-edge, passionate, results-driven, game changer, revolutionize, seamless, unlock, harness. If a sentence still works without the word, cut it.

14 · Developer setup

Build it

The site is one static HTML page on GitHub Pages with plain CSS custom properties. There's no framework and no component library. A Tailwind mapping is included in case a later version uses it.

1. Load the fonts

<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Geist:wght@400;500;600&family=Geist+Mono:wght@400;500&display=swap">

2. Paste the tokens

Copy the full :root block from brand-guidelines.md into styles.css. The core looks like this:

:root {
  --navy-900: #1C2233;  --navy-600: #5E6470;  --navy-100: #F3F3F1;  --navy-0: #FFFFFF;
  --champ-300: #E6DAC3; --champ-700: #7F6843;
  --font-sans: "Geist", ui-sans-serif, system-ui, sans-serif;
  --font-mono: "Geist Mono", ui-monospace, Menlo, monospace;
  --radius-lg: 12px;   --radius-full: 999px;
  --dur-base: 200ms;   --ease-out: cubic-bezier(.2,.7,.2,1);
}
body { background: var(--navy-100); color: var(--navy-900); font-family: var(--font-sans); }

3. Deploy on GitHub Pages

git init fahad-portfolio && cd fahad-portfolio
# add index.html, styles.css, /assets (photos, CV PDFs)
git add . && git commit -m "First version of portfolio"
git branch -M main
git remote add origin https://github.com/<fahad-username>/fahad-portfolio.git
git push -u origin main
# GitHub: Settings → Pages → Deploy from branch → main / root
