AI agent · built with Claude Code

GTM agent for LSN Signs

The finance lead who got tired of watching good leads slip, and built the thing that catches them.

LSN sells signage to restaurants and cafés opening across Dubai. The problem was never the work. It was timing. A group signs a lease, commits to an opening date, and needs signage within weeks, and we only heard about it if someone happened to notice. So I sat down with Claude Code and built an agent that watches for the opening instead of waiting for it. It finds new F&B operators daily, researches each one, scores the fit, and drafts the first message in our voice. I read every draft before it sends.

01

How it was built

One evening, three instruction files in plain English, and Claude Code. No framework, no dashboard, no vendor. The files are the product: they say what a good prospect looks like, what has to be verified, and how we talk. Claude Code reads them and does the run.

01 · what a good prospect looks like

Signals worth acting on, ranked. A job post for an outlet manager at an address that isn't trading yet beats a delivery-app listing every time. Openings in malls and towers count more than street shops, because one group usually buys again.

02 · what to verify

Every prospect must answer three questions before it counts: who owns the signage decision, which landlord's approval rules apply, and whether they already have a supplier. Each answer needs a source link. Can't verify it, it gets dropped.

03 · how we talk

Our voice, written down. Short, specific, no flattery. Every first message is built on one verified fact about that company, never a template. And the last rule is absolute: a person reads every draft before anything sends.

02

Four steps, run daily

  1. Find. It watches the public trail every opening leaves behind: job posts for outlet managers at addresses that aren't trading yet, mall directories, trade press. A group hiring a store manager for a mall unit has committed to a date and hasn't ordered a sign. That's the window.
  2. Research. Every prospect gets checked before it counts. Who owns the signage decision, which landlord's approval rules apply, whether they already have a supplier. No claim goes in without a source link. If it can't be verified, it gets dropped.
  3. Score. Each one gets rated out of ten on how well it actually fits. The dropped ones matter as much as the kept ones, and every rejection carries a reason I can check.
  4. Draft. It writes the first message built on one real fact about that specific company. No blast, no "I came across your profile." Then it stops. A person reads every draft before anything leaves the building.

04

What this is, and what it isn't

I built this myself in an evening. Not a product, not a pitch. Three instruction files written in plain English that tell Claude Code what a good prospect looks like, what to verify, and how we talk. The judgment is mine. Knowing that a job post beats a delivery-app listing as a buying signal came from selling signage, not from the model.

It's running. It produces real lists I can act on. What I don't have yet is months of reply data, and I'd rather tell you that than invent a number. The next step is letting it draft outreach straight into my inbox for review, which is already built and waiting on me to trust it enough.

The agent wasn't the only thing. I used the same setup to build a quote generator that replaced hours of hand-editing in Canva, and an AI lead form on the company site that qualifies an enquiry before it reaches a human. Finance guy, shipping the software the business runs on.
